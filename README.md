# MATERIA

لعبة واقع معزّز تعمل بالكامل داخل المتصفح. تفهم **مواد** أسطح غرفتك الحقيقية
وتحوّلها إلى فيزياء: المخدة تبلع الكرة، والطاولة ترتدّها وتشحنها.

---

## الفكرة في سطر واحد

مجسمات الغرف في الواقع المعزّز اليوم "غبية" — كل سطح جدار صلب بنفس الاحتكاك.
هنا كل سطح يُصنَّف في واحد من ستة تصنيفات مادية، والتصنيف يقود الارتداد
والاحتكاك والامتصاص وأسلوب اللعب نفسه.

## آلية اللعب

1. **وسّم** أسطح غرفتك (طري / سجاد / صلب / زجاج / معدن / أرضية).
2. **أرواح** تظهر وتتجمّع قرب الأشياء الطرية — والطري يمنحها درعاً.
3. **الكرة المباشرة لا تكفي.** لازم ترتدّ عن سطح صلب أو زجاج أو معدن
   لتُشحن الكرة، وحينها فقط تسقط الروح المحمية.
4. الأشياء الطرية تُفرِّغ شحنة الكرة — فمعرفة مواد غرفتك هي المهارة.

## الملفات

```
index.html            الصفحة الرئيسية — شرح + مختبر مواد تفاعلي
game.html             شاشة اللعب
assets/style.css      تنسيق الصفحة الرئيسية
assets/game.css       تنسيق واجهة اللعبة
assets/materials.js   نظام المواد — قلب المشروع
assets/physics.js     محرك فيزياء مكتوب يدوياً (كرة × صندوق موجّه × مستوى)
assets/game.js        محرك اللعبة (وضع AR + وضع المحاكاة)
```

لا توجد خطوة بناء (build). الاعتمادية الوحيدة هي three.js من CDN.

---

## ⚠️ مهم: لن يعمل بفتح الملف مباشرة

سببان:

1. الملفات تستخدم **ES Modules**، والمتصفح يرفضها عبر `file://`.
2. **الواقع المعزّز يتطلب HTTPS** إلزامياً.

لذلك لا بد من استضافة، أو خادم محلي للتجربة على الكمبيوتر فقط.

### تجربة محلية سريعة (وضع المحاكاة فقط)

من داخل مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. سيعمل وضع المحاكاة، ولن يعمل الـ AR
لأن `localhost` آمن لكن جوالك لن يصل إليه عبر HTTPS.

## 🔗 الحصول على رابط للجوال

### الأسرع — Netlify Drop

1. افتح <https://app.netlify.com/drop>
2. اسحب مجلد `MateriaAR` كامل وأفلته في الصفحة.
3. تحصل على رابط HTTPS فوراً. افتحه من جوالك.

### GitHub Pages

```bash
cd MateriaAR
git init
git add .
git commit -m "MATERIA"
git branch -M main
git remote add origin https://github.com/<اسمك>/materia.git
git push -u origin main
```

ثم من إعدادات المستودع: **Settings → Pages → Source: main / root**.
الرابط: `https://<اسمك>.github.io/materia/`

### Cloudflare Pages أو Vercel

كلاهما يقبل سحب المجلد أو ربط المستودع، ويعطي HTTPS تلقائياً.

| أندرويد + Chrome | ✅ | ✅ |

تلقائياً لوضع المحاكاة بنفس الفيزياء ونفس اللعب داخل غرفة ثلاثية الأبعاد.

## قرارات هندسية تستحق التوضيح

**لماذا لا يوجد تعرّف تلقائي بالذكاء الاصطناعي على الأجسام؟**
قراءة بكسلات الكاميرا داخل جلسة WebXR تتطلب صلاحية `raw-camera-access`
غير المتاحة على أغلب الأجهزة، فأي مسار يعتمد على SAM أو مصنّف صور داخل
الجلسة يكون هشاً. المسار الموثوق هو الوسم بلمسة واحدة. أما التعرّف
التلقائي فمُفعَّل عبر **التسميات الدلالية** التي يوفّرها WebXR
(`plane.semanticLabel`) على الأجهزة التي تدعمها — انظر `harvestPlanes`.

**لماذا محرك فيزياء مكتوب يدوياً؟**
الأشكال المطلوبة هي كرة مقابل صندوق موجّه ومستوى فقط. هذا حوالي ٢٠٠ سطر،
بدون أي تحميل، ولا يمكن أن يفشل في الإقلاع — بخلاف سحب محرك WASM من CDN.

**كيف يعمل الإخفاء؟**
الأشكال الموسومة تُرسم في وضع AR بـ `colorWrite: false`، أي تكتب العمق
دون اللون. النتيجة: ترى غرفتك الحقيقية، والأرواح تختفي فعلياً خلف أثاثك.
هذا أمتن من محاولة استخدام خريطة العمق مباشرة.

**لماذا ستة تصنيفات فقط؟**
اللعبة تحتاج أن تعرف أن المخدة *طرية*، لا أنها إسفنج ميموري فوم بماركة
معيّنة. المفردات الصغيرة = أسرع، تعمل أوفلاين، وأصعب في الانكسار.

## الحدود المعروفة

- القياس تقديري لا مطلق — كافٍ للعب، غير كافٍ لطباعة أغلفة بمقاسات دقيقة.
- الأشكال محدّبة مبسّطة (صناديق موجّهة)، ليست مجسمات دقيقة.
- المراسي (anchors) مطلوبة كميزة اختيارية؛ حفظ المسح بين الجلسات
  هو الخطوة المنطقية التالية.
